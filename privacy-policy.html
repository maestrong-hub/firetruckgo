📋 개요

소방출동내비(이하 "앱")는 소방관의 출동 업무를 지원하기 위한 목적으로 제작되었습니다. 본 방침은 앱이 수집하는 정보와 사용 방법을 안내합니다.

앱은 사용자의 개인정보 보호를 중요하게 생각하며, 관련 법령을 준수합니다.

🔒 정보 보호 원칙

  • 수집한 개인정보는 명시된 목적 이외에 사용하지 않습니다.
  • 위치 정보는 서버에 저장되지 않으며 기기 내에서만 처리됩니다.
  • 음성 인식 데이터는 주소 변환 후 즉시 삭제됩니다.
  • 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

📸 소방시설 사진 정책

  • 누구나 사진을 업로드할 수 있습니다.
  • 하루 기기당 최대 20장까지 업로드 가능합니다.
  • 신고된 사진은 24시간 이내 미조치 시 자동 삭제됩니다.
  • 동일 기기에서 신고 3회 누적 시 7일간 업로드가 제한됩니다.
  • 타인의 개인정보가 포함된 사진은 즉시 신고해주세요.

🗺 제3자 서비스

앱은 아래 외부 서비스를 사용합니다.

  • 카카오맵 API — 지도, 로드뷰, 주소 검색 카카오 개인정보처리방침 적용
  • 공공데이터포털 응급의료기관 API — 주변 응급실 정보
  • 국가화재정보시스템 — 소화전 위치 정보

각 서비스의 개인정보 처리방침은 해당 서비스의 정책을 따릅니다.

👤 사용자 권리

  • 언제든지 앱 내 저장된 데이터를 삭제할 수 있습니다.
  • 앱 설정에서 각 권한을 개별적으로 철회할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터가 삭제됩니다.
